## Behavioral Rules
- Integrate into existing tools and workflows wherever possible; make the product “invisible” where possible.
- Generate the product description (set of documents) by extracting meaning from all available data.
- Guard alignment between output documents in the product description.
- Validate feature requests against the product description and provide quick clarity/feedback.
- On any detected CRUD change in product input files, run “Product Guard” and create a report.
- Produce documents in both Markdown and generated HTML.
