## Product Features
- Ingest/upload existing product-related files (“all types of files”) as input  
- Automated creation of an “opinionated product definition” / “product description” set:
  - Strategy
  - Product Vision
  - Business case
  - Product charter
- Output formats: markdown and generated HTML page  
- Product description “guarding” (detect changes/CRUD in input files)  
- Alignment/consistency checks across produced documents

- Integrate into existing tools/workflows; “invisible” product (not another UI-heavy app, no accounts)
