When I start my day (or need to decide what to do next in my deals), I want the system to tell me my prioritized next actions and let me execute them immediately, so I can move deals forward without spending time on CRM admin or figuring it out myself.

**Confidence:** High

## User Flows or Journeys
- Morning start: open app (ideally no login) → ask “what do I do first?”; current state is checking 3–5 tools (CRM/email/calendar/Slack)
- Figuring out next action:
  - Current: open CRM → click pipeline/tasks/dashboards → check notes/last email → decide manually → forget items
  - Desired: open system → it tells you (or you ask) “what should I do now?” → receive prioritized actions with who/context/suggested message
- Executing an action:
  - Current: find contact/record → read notes → switch to email → write → maybe log → update stage manually
  - Desired: system suggests action → user confirms in chat (“send this/call now/schedule”) → executes immediately → logs automatically → pipeline updates itself
- Capturing activity:
  - Current: after call/email, user must log notes; pipeline stage needs manual update; often skipped
  - Desired: emails/calls captured automatically; notes generated/suggested; deal stage updated without asking
- Staying on top of deals:
  - Current: dashboards require interpretation; still unclear what to do; follow-ups fall through
  - Desired: system flags risk (“going cold”, “no reply in 3 days”) and converts into executable actions
