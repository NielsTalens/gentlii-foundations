1 Creation of the product description

A user uploads all types of files they can find that state something about the product or ideas for a product
This set is called the `foundations input`
Gentlii will use different agent to create:
- Strategy
- Product Vision
- Business case
- Product charter
The set of documents is called the `product description`

These are written both in markdown as in a generated html page

2 Product description guarding
If there is any change (crud) detected in `foundation input` files
And a `product description` is generated
The product guard agent will check whether the individual definitions align.

3 Feature validation
Whenever a new idea for a feature is inputted
The `feature vakidator` will check how well it aligns with the `product description`
It will result with feedback and scores
The user knows whether the idea aligns with the product.
